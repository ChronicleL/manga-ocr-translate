漫画汉化工作台 Manga Studio（Windows 64 位）
==================================================

启动
----
双击 MangaStudio.exe 即可，无需安装 Python 或任何依赖。

窗口出现后，识别模型在后台加载（约 10～60 秒），期间状态栏底部会有一条进度条；
加载完成后右下角显示实际推理后端，例如「检测 Dml · OCR cpu」表示检测已走 GPU（DirectML）加速。
若显示「检测 CPU（未启用 GPU 加速）」，说明当前显卡/驱动不支持 DirectML，仍可正常使用，只是检测会慢很多。

首次识别前需要联网下载日文 OCR 模型（约 420 MB，默认走 hf-mirror.com 镜像），
之后缓存在 %USERPROFILE%\.cache\huggingface，可离线重复使用。

基本流程
--------
1. 新建项目：选一个文件夹，每一话一个项目。图片、识别结果、译文、校对状态都存在这个文件夹里，
   下次「打开项目」可以接着做。
2. 导入页面（任选一种，导入后自动识别，可在「识别」菜单里关闭）
   · 导入 → 图片文件 / 文件夹 / 剪贴板图片（Ctrl+V）；也可以把文件直接拖进窗口
   · 截图：框选屏幕上的区域（比如浏览器里的漫画页）
   · 网页：粘贴章节网址，列出页面里的图片，勾选后导入。图片加载失败时可以改 Referer 再重新加载。
     只支持直接写在网页里的图片，用 JavaScript 动态生成的、需要登录的站点请改用截图。
3. 翻译：画布底部浮动栏的「翻译」菜单（本页 / 全部页面 / 只翻译还没有译文的页面），
   并在菜单里选择翻译通道。AI 翻译需要先在「设置」里填写 API Key。
4. 校对：右侧每个文本块一张卡片，可以直接改原文和译文。点画布上的框或点卡片会互相定位。
   机翻不会覆盖已勾选「已校对」或你手写过的译文；单独点某一块的刷新按钮才会强制重翻（已校对的除外）。
5. 看效果：浮动栏的「叠图」按钮（或空格键）在原图和译文叠图之间切换。
6. 导出：「导出」菜单可导出整话图片（PNG / JPG，按页面顺序编号）、当前页、文本、JSON。

快捷键
------
Ctrl+N 新建项目      Ctrl+O 打开项目        Ctrl+I 导入图片       Ctrl+V 粘贴剪贴板图片
Ctrl+Shift+S 截图    F5 识别当前页          Ctrl+T 翻译本页       Ctrl+Shift+T 翻译全部
Ctrl+E 导出整话      Ctrl+, 设置            Alt+←/→ 上一页 / 下一页
Alt+↑/↓ 上一个 / 下一个文本块（光标直接进入译文框）
Ctrl+Enter 标记当前块已校对并跳到下一块（再按一次取消）
Ctrl+B 显示 / 隐藏文本块框     空格 在原图与叠图之间切换（焦点在画布时）
画布：Ctrl+滚轮缩放，拖动平移，双击适应窗口。

文件
----
与 exe 同目录，使用后自动生成：

  studio_config.json      窗口状态、主题、最近项目、上次的网址和导出文件夹
  translate_config.json   翻译设置与 AI 接口预设（可能含 API Key，请勿外发）
  engine_config.json      性能设置：执行后端 / CPU 线程 / OCR 批处理

检查安装是否正常（可选）
------------------------
在命令行里执行：  MangaStudio.exe --selftest result.txt
等待约 20 秒后程序自动退出，result.txt 第一行是 OK 加后端信息，即模型加载正常；以 FAIL 开头则是原因。

注意
----
· 请保持文件夹结构完整，_internal 目录不可删除或移动。
· 检测模型来自 dmMaze/comic-text-detector（GPL-3.0）的 ONNX 导出，
  manga-ocr 使用 Apache-2.0 许可的 kha-white/manga-ocr-base；
  界面库 PySide6-Fluent-Widgets 为 GPLv3，PySideSix-Frameless-Window 为 LGPLv3。
  对外分发前请留意相应许可证。
